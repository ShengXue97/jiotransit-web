# JioTransit website

The website for JioTransit, the Singapore bus and MRT app: live bus timings,
MRT routes, and an alert before your stop.

**Live site:** https://shengxue97.github.io/jiotransit-web/

- [Home](https://shengxue97.github.io/jiotransit-web/)
- [Free beta](https://shengxue97.github.io/jiotransit-web/beta/) (iPhone via TestFlight, Android via Google Play testing)
- [Support](https://shengxue97.github.io/jiotransit-web/support/)
- [Privacy policy](https://shengxue97.github.io/jiotransit-web/privacy/)

Static pages served by GitHub Pages from `main`; pushing to `main` publishes
the site. One stylesheet (`assets/site.css`) and a small script
(`assets/nav.js`) for instant page switches.
